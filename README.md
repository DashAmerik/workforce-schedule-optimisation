# workforce-schedule-optimisation
Python linear programming project using PuLP to optimise staff schedules, balancing wage costs, workload fairness and skill requirements.

This project was completed as individual coursework for MSCI151 at Lancaster University, receiving 72% overall. Feedback praised my fairness analysis, complete user interface and clear writing, while highlighting improvements needed in code reusability, documentation and the combined fairness-and-skills model.

Through this project, I learnt to formulate and solve linear programming problems using PuLP, explore trade-offs between cost and workload fairness, and communicate results through tables, visualisations and a management report. The feedback also taught me the importance of reusable functions and checking that the implemented objective matches the intended mathematical model.
